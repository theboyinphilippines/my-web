## 概念表

将《财富自由之路》的每节点概念统计出来

### 家人：

除自己外最关心的人，无论什么情况，都能提供包容、温暖的人。

```
家人跟自己接触最多，接触时间最多的人放在首位，他们会占据你最多的注意力，应该首要关心；家是港湾，家里如果都不能提供包容、温暖，还要家干嘛。
```

### 朋友：

能一起共同成长或有可聊话题的人。

```
一起成长的人，能够跟上彼此节奏，如果节奏不同，各种价值观不同步，比如金钱观、消费观、教育观等；朋友在一起没话说，会很尴尬，我说的你没兴趣，你说的我没兴趣，最终渐行渐远。
```

### 婚姻：

互相尊重，没有芥蒂，不说话也不会不自在的地方。

```
关系对等很重要，婚姻中存在你尊我卑的情况，就出现一方常指责另一方，所以需要互相尊重；夫妻之间有心结，长时间下去会出现猜疑，有信任危机，关系逐渐破裂；虽然不一定每天都有很多话说，但不说话也不会不自在，自己忙自己的，否则下班后都不想回家。
```

### 人工智能：

拓展我技能、知识面，提升效率，助我生产的工具。

```
人最终都靠时间进行生产，人工智能作为工具，就是帮我提高生产效率、质量的。
```
